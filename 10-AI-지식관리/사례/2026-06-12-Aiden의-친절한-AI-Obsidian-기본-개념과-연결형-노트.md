## 영상 요약

영상은 흩어진 메모를 단순히 보관하는 데 그치지 말고, 노트끼리 연결해 개인 지식 시스템으로 활용하자고 설명한다. 설치부터 시작해 Vault, Markdown, 링크·백링크, 태그, 그래프, 속성, Canvas와 플러그인을 차례로 소개한다.[1]

| 개념 | 영상의 설명을 쉽게 풀면 |
|---|---|
| Vault | 노트와 첨부 자료가 들어 있는 로컬 폴더 |
| Markdown | 다른 편집기에서도 읽을 수 있는 텍스트 기반 기록 형식 |
| 폴더 | 노트가 보관되는 위치 |
| 링크·백링크 | 관련 노트로 이동하고, 어떤 노트가 현재 노트를 참조하는지 확인하는 연결 |
| 태그 | 같은 분류나 상태의 노트를 모아 보는 표시 |
| 속성 | 출처·저자·날짜·상태 등 노트에 붙이는 구조화된 정보 |
| 그래프 뷰 | 노트와 연결을 점과 선으로 보는 화면 |
| Canvas | 노트·이미지 등을 펼쳐 관계를 배치하는 작업 공간 |

위 표는 영상의 개념 설명을 요약한 것이다. 시연은 기본 문법 작성, 노트 연결, 태그·속성 검색, Canvas 배치에 집중하며 AI 연동 자체를 구축하는 영상은 아니다.[1]

## 분석 — 무엇이 유용하고 무엇은 과장하기 쉬운가?

**1. AI와 함께 쓰기 좋은 이유는 파일이 열려 있기 때문이다.**

공식 도움말에 따르면 Vault는 로컬 폴더이고 노트는 Markdown 텍스트여서 외부 편집기로도 수정할 수 있다.[12] 따라서 사람은 Obsidian으로 읽고 에이전트는 허용된 파일을 편집하는 협업이 가능하다. 다만 이는 구조적 적합성이지, 파일을 열었다고 AI가 모든 노트를 자동으로 이해한다는 뜻은 아니다.

**2. 폴더와 링크는 경쟁하는 정리 방식이 아니다.**

이 프로젝트처럼 주제별 폴더가 이미 있다면 그대로 유지하고 필요한 곳에 관련 문서 링크를 추가하는 편이 단순하다. 하나의 문서를 여러 폴더에 복제하기보다 연결로 다른 주제와의 관계를 표현할 수 있다.

**3. 연결 수보다 연결의 의미가 중요하다.**

영상은 느슨하게라도 관련 노트를 이어 보라고 권한다.[1] 그러나 연구 노트에서는 “관련 있음”만 반복하기보다 “반례”, “설치 방법”, “비교 대상”처럼 관계를 한 문장으로 설명하는 것이 유용하다. 모든 노트를 서로 잇는 것은 탐색 잡음을 늘릴 수 있다.

**4. 첫 목표는 멋진 그래프가 아니라 기록의 재사용이다.**

플러그인·속성·Canvas를 한 번에 도입하면 기록보다 설정에 시간을 쓰기 쉽다. 먼저 노트와 출처를 남기고, 지난 자료를 다시 찾아 실제 비교나 판단에 쓰는 흐름을 확인하는 것을 추천한다.

## 공식 문서 교차 확인

| 영상에서 다룬 내용 | 확인 및 해석 |
|---|---|
| 로컬 Markdown과 Vault | 공식 도움말의 파일 저장 설명과 일치한다.[12] |
| 그래프 뷰의 점과 선 | 공식 문서는 점을 노트, 선을 내부 링크로 설명한다. AI가 본문을 읽어 의미 관계를 자동 생성하는 기능과는 다르다.[4] |
| 백링크의 역할 | 영상에서도 다른 노트가 현재 노트를 참조하는 역방향 탐색으로 설명한다. 새로운 의미 관계의 정확성을 보증하는 기능으로 읽으면 안 된다.[1] |

창업 배경에 관한 영상의 서술, 플러그인 개수, 유료 동기화 요금은 이 개념 정리에서 별도로 검증하거나 현재 수치로 인용하지 않았다.

## 이 프로젝트의 활용 제안

- 기존 프로젝트 폴더와 README 탐색 구조를 유지한다.
- 노트에 출처와 핵심 요약, 자신의 생각을 남긴다.
- 관련 문서는 상대 Markdown 링크로 연결해 GitHub에서도 읽을 수 있게 한다.
- 속성은 실제로 검색하고 싶은 항목이 생겼을 때 추가한다.
- 도입 여부는 “지난 노트를 다시 찾고 다른 문서에 활용하기 쉬워졌는가”로 판단한다.

이 제안은 영상의 직접 발언이 아니라 현재 저장소에 맞춘 분석이다. 로컬 파일이라도 AI·플러그인에 접근을 허용할 때는 전송 범위와 수정 권한을 별도로 확인해야 한다.
