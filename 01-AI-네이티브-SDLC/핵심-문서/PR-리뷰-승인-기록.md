# PR-리뷰-승인-기록.md

## 목적

`PR-리뷰-승인-기록.md`는 변경이 intent·spec·plan에 부합하는지, 어떤 리뷰 결과가 있었는지, 누가 어떤 위험을 승인했는지 정리한다. PR 시스템이 원본 기록이면 이 문서는 PR 본문 또는 연결 문서로 사용한다.

## 출처에서 확인한 내용

- AI 기반 PR 리뷰는 버그, 보안, spec·plan 준수, 설계 원칙처럼 일관된 검토 패스를 적용할 수 있다.[3]
- 작성 에이전트와 최종 승인자를 분리하고, 코드 오너의 승인과 브랜치 보호를 유지하는 방식이 제시된다.[3]

## 실무 가이드

- 관련 intent·spec·plan·구현·검증 기록을 한 곳에서 연결한다.
- AI 리뷰와 인간 리뷰의 판단을 구분해 기록한다.
- 고위험 변경은 승인자·승인 범위·남은 위험을 명시한다.
- 중요 발견 사항의 해결 PR 또는 후속 이슈를 링크한다.
- 반복되는 리뷰 지적은 규칙 파일·정적 검사·훅으로 환류할지 결정한다.

```md
- 승인자:
- 승인 범위:
- 수용한 위험:

## 규칙 환류
```

## 점검 목록

- [ ] intent·spec·plan과 실제 변경을 비교했는가?
- [ ] 자동·AI 리뷰와 인간 판단을 구분했는가?
- [ ] 고위험 변경의 승인자가 명시됐는가?
- [ ] 미해결 항목이 후속 작업으로 연결됐는가?
- [ ] 반복 지적을 가드레일로 환류할지 검토했는가?
