# 에이전트 친화적 웹

## 정의

에이전트 친화적 웹은 AI 에이전트가 웹사이트의 정보를 읽고 기능을 안정적·안전하게 수행할 수 있도록 웹 UI, API, 도구 인터페이스, 권한 체계를 설계하는 접근이다.

## 핵심 기술

- **WebMCP**: 웹페이지 기능을 AI 에이전트의 구조화된 도구로 노출하는 제안 단계의 웹 표준
- **브라우저 에이전트**: 화면, DOM, 접근성 트리를 분석해 웹을 조작하는 에이전트
- **Chrome DevTools MCP**: 개발자 도구 인터페이스를 통해 웹을 검사·자동화하는 방식
- **Playwright 기반 자동화**: 브라우저를 코드로 제어하는 테스트·자동화 방식

## 핵심 원칙

1. 화면 조작보다 구조화된 도구 인터페이스를 우선 검토한다.
2. 읽기 전용 기능과 상태 변경 기능을 명확히 구분한다.
3. 상태 변경 작업에는 사용자 확인, 최소 권한, 서버 측 권한 검증을 적용한다.
4. 도구의 이름·설명·입력 스키마·오류 처리를 명확히 정의한다.
5. 도구 호출 이력과 결과를 감사 로그로 남긴다.
6. 프롬프트 인젝션과 권한 오남용을 전제로 보안 정책을 설계한다.

## 주요 검토 항목

| 주제 | 질문 |
|---|---|
| 기능 발견 | 에이전트가 사이트에서 사용할 수 있는 기능을 어떻게 알 수 있는가? |
| 실행 방식 | UI 클릭, 공개 API, MCP, WebMCP 중 어떤 인터페이스가 적합한가? |
| 권한 | 에이전트가 수행 가능한 작업과 사용자 확인 기준은 무엇인가? |
| 신뢰성 | UI 변경이나 네트워크 실패에도 안정적으로 동작하는가? |
| 관측성 | 호출 주체, 입력, 결과, 오류를 추적할 수 있는가? |
