# 위키의 목적과 판단 기준

## 목적 — 사용자 확정

AI 에이전트 관련 자료와 직접 검증한 경험을 축적하고 연결한다. 내가 에이전트 관련 지식이 필요할 때 사용하는 지식 기반으로 사용한다.

## 활용 범위

도구 선택이나 실제 적용 판단에만 한정하지 않는다. 개념 이해, 과거 자료와 경험 다시 찾기, 관련 지식 연결, 비교와 설명, 필요할 때의 실제 적용에 활용한다. 모든 자료에 당장 실행할 과제나 활용 결과물을 요구하지 않는다.

## 기본 운영 기준

- **찾아 쓸 수 있게 남긴다.** 자료의 양보다 필요한 지식과 근거를 다시 찾을 수 있는지를 중요하게 본다.
- **사실과 해석을 구분한다.** 출처에서 확인한 사실, AI의 분석, 사용자가 직접 밝히거나 채택한 판단을 구분한다. AI가 사용자의 의견을 대신 만들어 기록하지 않는다.
- **경험의 확인 범위를 남긴다.** 직접 실행해 확인한 결과, 사용자 보고, 문서 조사만으로 확인한 내용을 구분한다. 시연을 실제 검증으로 취급하지 않는다.
- **기존 지식을 먼저 찾는다.** 새 자료를 기존 문서와 비교하고, 중복 문서를 늘리기보다 적절한 기존 문서를 갱신하거나 연결한다.
- **모르는 부분을 드러낸다.** 출처가 없거나 오래되었거나 서로 충돌하는 설명은 불확실성과 확인 필요 사항을 표시한다.
- **변경 범위를 통제한다.** 파일 삭제·이동, 핵심 결론 변경, 외부 전송은 실행 전에 별도로 확인한다.

## 운영 범위

- 기존 주제별 구조와 한국어 Markdown 문서를 유지한다.
- Obsidian은 지식을 읽고 탐색하는 공간으로 사용한다.
- AI 에이전트는 허용된 범위에서 자료를 정리하고 관련 문서의 갱신을 돕는다.
- 자동 수집·주기 작업·외부 동기화·플러그인 설치 권한을 이 문서만으로 부여하지 않는다.

## 성공 기준

- 필요한 질문에 관련 문서와 근거를 찾아 연결할 수 있는가?
- 설명의 출처와 검증 범위, 불확실성을 알 수 있는가?
- 새 자료나 경험이 기존 지식과 연결되어 이후에 다시 쓰이는가?
