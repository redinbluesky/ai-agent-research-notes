## 한눈에 보기

이 영상은 AI 브라우저 Aside에서 Claude를 모델 제공자로 연결한 뒤, 네이버 쇼핑과 쿠팡에서 로봇청소기 후보의 판매가·배송비를 수집하고 Google Sheets에 비교표를 작성하는 흐름을 시연한다.[1] 핵심은 LLM이 답변만 생성하는 데 그치지 않고, 브라우저에서 검색·클릭·정보 추출·웹앱 입력을 연속 실행하는 데 있다.

## 제품·통합 방식의 확인

### 영상 설명과 공식 문서의 구분

영상은 Claude와 Aside를 연결하는 통로를 MCP로 설명한다.[1] 그러나 실제 도입 시에는 아래 두 경로를 구분해야 한다.

| 경로 | 목적 | 공식 문서상 방식 |
|---|---|---|
| Aside 내부 모델 연결 | Aside 에이전트가 Claude 모델을 사용 | `Settings > Models > Providers`에서 Claude Pro 또는 Max 구독을 OAuth로 연결한다.[2] |
| 외부 에이전트의 도구 연결 | Claude Code 등 다른 MCP 클라이언트가 Aside 브라우저 기능을 호출 | `aside mcp`를 MCP 서버로 실행하고, MCP 클라이언트 설정에 `aside mcp` 명령을 등록한다.[3] |

따라서 영상 화면의 작업은 **Aside 내부에서 Claude를 모델 제공자로 선택해 브라우저 작업을 수행하는 흐름**으로 이해하는 것이 적절하다. 외부 Claude Code 또는 다른 에이전트가 Aside를 MCP 도구로 호출하는 구성은 별도의 개발자 설정이다.[2][3]

### Aside의 역할

Aside는 로그인된 웹사이트·계정·브라우징 기록 등을 설정된 권한 범위에서 사용해 브라우저 작업을 수행하도록 안내한다.[4] 공식 사이트는 웹사이트와 계정을 직접 사용해 작업을 수행한다는 제품 방향을 제시하며, 민감한 행동은 검토 단계로 통제한다고 설명한다.[5]

## 재사용 가능한 업무 자동화 패턴

```text
업무 요청
  → 여러 웹사이트에서 후보·조건 수집
  → 동일 기준으로 값 정규화
  → 총비용·우선순위 판단
  → 스프레드시트에 근거 링크와 함께 기록
  → 사람이 예외와 최종 행동을 검수
```

이 패턴은 가격 비교 외에도 공급업체 후보 조사, 공고·지원자 목록 정리, 웹 리서치의 증빙 링크 수집, 정기 조회 결과의 표 업데이트에 적용할 수 있다. 다만 자동화의 목표는 “최저가를 확정하는 것”이 아니라 **검증 가능한 비교표 초안을 빠르게 만드는 것**으로 두는 편이 안전하다.

## 실무 적용 시 보완점

| 통제 항목 | 영상 시연 | 실무 보완안 |
|---|---|---|
| 대상 동일성 | 동일 모델 검색에 의존 | 모델번호, 용량, 색상, 구성품, 판매자 조건을 별도 필드로 확인 |
| 비교 규칙 | 판매가와 배송비 비교 | 할인·쿠폰·회원가·카드 혜택·설치비·배송 가능 지역을 분리 기록 |
| 데이터 품질 | 화면에서 발견한 값 사용 | 수집 시각, 원문 URL, 확인 실패 사유, 중복 판단 근거 기록 |
| 결과 검증 | 링크로 재확인 가능 | 표본 검수와 `검토 필요` 상태를 운영 규칙으로 지정 |
| 외부 행동 | 중요 작업은 직접 확인 권고 | 결제·제출·발송·공개는 반드시 승인 대기 상태로 유지 |
| 재현성 | 일회성 자연어 요청 중심 | 입력 조건, 출력 열, 예외 기준, 승인 지점을 프롬프트 템플릿으로 고정 |

쇼핑 검색 결과는 가격·재고·배송 조건이 수시로 바뀌고, 검색 결과의 제품이 완전히 동일하다는 보장이 없다. 따라서 모델번호가 다르거나 배송비를 확인하지 못한 행은 자동 판정에서 제외하고 사람이 검토하도록 설계해야 한다.

## 도입 판단

### 적합한 작업

- 여러 사이트의 가격·재고·배송 조건을 모아 비교표 초안을 만들기
- 정해진 조사 기준에 따라 후보와 근거 링크를 수집하기
- 반복 조회한 결과를 스프레드시트의 정해진 열에 갱신하기
- 비민감 정보가 들어간 반복 웹 폼을 사람의 검토 전 단계까지 작성하기

### 사람 승인 없이는 맡기지 않을 작업

- 결제·주문·계약·환불 등 되돌리기 어려운 거래 확정
- 개인정보, 금융정보, 건강정보, 인증 수단 입력
- 외부 수신자에게 전송되는 메일·메시지·게시물의 최종 발송
- 법무·재무·구매 결정을 단일 에이전트 수집 결과만으로 확정하는 일

## 결론

이 사례의 가치는 Claude라는 특정 모델보다, 모델이 기존의 웹사이트·로그인 상태·스프레드시트에 걸친 작업을 실행할 수 있게 한 **브라우저 에이전트 실행 계층**에 있다. 성공적인 도입의 기준은 클릭 자동화량이 아니라, 비교 기준·근거 링크·예외 처리·승인 절차를 갖춘 결과물을 만들 수 있는지다. 실제 설치 파일은 공식 다운로드 페이지에서 운영체제에 맞는 설치 프로그램을 받아 사용한다.[6]
