# 유튜브 분석 도구

YouTube URL 또는 영상 ID에서 분석에 필요한 메타데이터, 챕터, 자동 자막을 추출하고 AI 분석용 Markdown 입력 자료를 생성합니다.

## 설치·실행

이 폴더에서 `uv`를 사용해 실행합니다. `yt-dlp`는 `pyproject.toml`의 의존성으로 자동 설치됩니다.

```bash
uv run 유튜브_분석.py "https://youtu.be/VIDEO_ID"
```

결과 폴더를 지정하려면 다음처럼 실행합니다.

```bash
uv run 유튜브_분석.py "https://youtu.be/VIDEO_ID" --결과-폴더 "결과"
```

## 생성 결과

```text
결과/<영상-ID>/
├─ 메타데이터.json
├─ 챕터.md
├─ 자막-원본.ko.vtt 또는 자막-원본.en.vtt
├─ 자막-정리본.md
└─ 분석-입력자료.md
```

자막을 구할 수 없는 경우에는 `자막-추출-오류.txt`를 남기며, 메타데이터·챕터·분석 입력 문서는 가능한 범위에서 생성합니다.

## 처리 원칙

- 영상 파일과 오디오는 다운로드하지 않습니다.
- 한국어 자동 자막을 우선 시도하고, 없으면 영어 자막을 시도합니다.
- VTT의 시간 코드, 태그, 인접 중복 문장을 정리합니다.
- 생성된 원본 자막과 중간 산출물은 로컬 `결과/`에만 보관합니다.
- 최종 분석 문서는 각 주제의 `사례/` 폴더에 별도로 저장합니다.

## 테스트

python -m unittest discover -s tests -v

## 제한 사항

- 비공개·삭제·연령 제한 영상은 추출할 수 없습니다.
- 영상에 자막이 없거나 YouTube가 자동 자막을 제공하지 않으면 자막 추출에 실패할 수 있습니다.
- YouTube의 제공 정책이나 로그인·지역 제한에 따라 결과가 달라질 수 있습니다.
