# AI Agent Research Notes

AI 에이전트와 이를 둘러싼 개발 방법론, 웹 인터페이스, 설정, 로컬 실행 환경, 에이전트 네이티브 도구를 출처 기반으로 조사·분석·요약한 한국어 리서치 노트입니다.

## 주제

### 01. AI 네이티브 SDLC

AI 에이전트를 계획·설계·구현·테스트·배포·운영 전 과정에 연결하는 개발 방법론을 정리합니다. 의도·명세·계획을 문서화하고, AI의 초안 생성과 사람의 승인·지속적 검증을 함께 다룹니다.

- [01-AI-네이티브-SDLC](01-AI-네이티브-SDLC/)

### 02. 에이전트 친화적 웹

AI 에이전트가 웹의 정보와 기능을 안정적·안전하게 읽고 실행할 수 있도록 UI, API, 도구 인터페이스, 권한 체계를 설계하는 방법을 정리합니다. WebMCP, 브라우저 에이전트, 구조화된 도구 호출, 상태 변경 보호와 감사 가능성을 주요 관심사로 둡니다.

- [02-에이전트-친화적-웹](02-에이전트-친화적-웹/)

### 03. 에이전트 설정

Claude Code, Codex, Gemini CLI, Hermes 등 에이전트의 지침·스킬·훅·Effort·권한·실행 환경을 구성하고 검증하는 방법을 정리합니다. 제품별 기능 차이를 구분하면서 프로젝트 문맥·규칙·자동화·안전 제어와 서브에이전트 위임·Goal·역할 기반 오케스트레이션을 관리하는 방식을 다룹니다.

- [03-에이전트-설정](03-에이전트-설정/)

### 04. 로컬 LLM 구축

AI 에이전트에 연결할 로컬·온디바이스 LLM의 선정, 설치, 서빙, 양자화, 하드웨어 성능 검증 방법을 정리합니다. 모델·서빙 엔진·메모리·GPU·라이선스와 실제 측정 환경을 함께 검토합니다.

- [04-로컬-LLM-구축](04-로컬-LLM-구축/)

### 05. 에이전트 네이티브 도구

에이전트가 단순 보조 기능을 넘어 분석·편집·제작·렌더링을 직접 수행하도록 설계된 도구와 인터페이스를 정리합니다. 사람이 수정 가능한 중간 산출물, 권한·동의, 검수·복구, 라이선스와 운영 위험을 중심으로 평가합니다.

- [05-에이전트-네이티브-도구](05-에이전트-네이티브-도구/)

### 06. 구조화된 AI 판단 모델

자유 형식 텍스트 대신 선택·점수·확률을 반환하는 AI 판단 모델과 API를 정리합니다. 모델 라우팅, 분류·점수화, 자동 처리와 사람 검토의 분기, 확률·임계값 기반의 안전한 자동화를 다룹니다.

- [06-구조화된-AI-판단-모델](06-구조화된-AI-판단-모델/)

### 07. 에이전트 트렌드

YouTube에 게시된 GitHub Trending 주간 브리핑을 업로드일 기준으로 기록하고, 순위 변화와 저장소의 기능 주장을 에이전트 운영·검증·권한·법적 경계 관점에서 분석합니다. 순위와 스타 수는 각 영상 또는 원출처의 수집 시점 스냅샷으로 구분해 다룹니다.

- [07-에이전트-트렌드](07-에이전트-트렌드/)

### 08. 에이전트 업무적용

AI 에이전트를 기업의 실제 업무에 적용하기 위한 업무 재설계, 도메인 모델링, 실행 환경, 권한·승인, 검증·관측, 비용·성과 측정을 정리합니다. 프롬프트 활용을 넘어 에이전트가 제한된 업무 행동을 안전하게 실행하고 실제 결과를 검증하는 운영 구조를 다룹니다.

- [08-에이전트-업무적용](08-에이전트-업무적용/)

여러 에이전트·브라우저·분석 도구를 연결해 구체적인 구현 과제를 깊게 검토합니다. 기존 웹앱의 업무 지식 복원과 사람·에이전트 공용 차세대 구조를 중심으로, Aside·REA의 조사, Codex·Claude Code의 야간 개발, 브라우저 검증과 SDLC 전반의 유지보수·미래 변경 비용을 다룹니다.
