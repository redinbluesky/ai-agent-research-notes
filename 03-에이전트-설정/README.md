# 에이전트 설정

Claude Code, Codex, Gemini CLI 등 **에이전트 자체의 지침·기능·권한·실행 환경을 설정하는 방법**을 정리한다.

## 문서 구성

- **사례/**: 출처 정보와 출처의 내용을 요약한다. 공식 문서에 따른 보충 사항은 원출처의 설명과 구분한다.
- **산출물/**: 사례와 공식 문서를 바탕으로 실제 참고할 도구별 설정 가이드를 정리한다. 이 주제에서는 빈 템플릿이 아니라 설명·구성 예시·검증 방법·근거를 포함한 최종 문서를 뜻한다.
- **README.md**: 도구별 설정 문서와 출처별 사례를 찾아보는 안내다.

새 자료를 추가할 때는 사례를 출처별로 남기고, 확인된 설정 방법은 해당 도구의 산출물에 통합한다. 예시는 연구 자료이며 실행 설정의 설치·변경과 구분한다.

## 도구별 설정

| 도구 | 산출물 | 현재 정리 범위 |
|---|---|---|
| Claude Code | [Claude Code 설정](산출물/Claude-Code-설정.md) | CLAUDE.md, Rules, Skills, Hooks, Agents의 역할·구조·적용 방법 |
| Codex | 아직 작성하지 않음 | 후속 자료 확보 시 `산출물/Codex-설정.md`로 정리 |
| Gemini CLI | 아직 작성하지 않음 | 후속 자료 확보 시 `산출물/Gemini-CLI-설정.md`로 정리 |

## 자료 추가 기준

- 사례 파일명은 `YYYY-MM-DD-출처-주제.md`로 작성한다.
- 제품마다 파일명과 기능이 같다고 가정하지 않는다. **저장 위치·적용 범위·로딩 및 실행 시점·호출 주체·권한 및 차단 범위·검증 방법·버전 및 출처**를 확인한다.
- 도구별 설정 가이드는 자료가 확보되면 만들고, 이후 자료를 누적해서 보강한다. 빈 문서는 미리 만들지 않는다.
- 아직 확인하지 않은 기능을 지원 또는 미지원으로 단정하지 않는다.
