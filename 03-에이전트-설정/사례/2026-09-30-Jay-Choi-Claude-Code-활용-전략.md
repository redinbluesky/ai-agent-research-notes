## 공식 문서로 확인한 보충 사항

### Effort는 품질 점수가 아니라 작업 강도·자율성의 선택이다

Claude Code는 세션에서 `/effort` 또는 `--effort`로 Effort 수준을 설정할 수 있으며, 사용 가능한 수준은 모델에 따라 다르다. 공식 CLI 문서는 `low`, `medium`, `high`, `xhigh`, `max` 등을 예시로 든다.[3]

또한 스킬 또는 서브에이전트의 frontmatter에 있는 `effort`는 활성화된 동안 세션 수준을 덮어쓸 수 있다. 따라서 영상의 "일반 작업은 Medium" 같은 값은 보편적인 기본값이 아니라, 작업 위험도·비용·지연·원하는 자율성에 맞춰 비교해야 할 출발점이다.[1][3]

### `AGENTS.md` 공유에는 로딩 조건이 있다

영상의 공통 지침 파일 전략은 유용하지만, `CLAUDE.md`와 `AGENTS.md`가 언제나 자동으로 함께 로딩되는 것은 아니다. 기본 설정에서는 현재 디렉터리 또는 상위 경로에 `CLAUDE.md`나 `CLAUDE.local.md`가 없을 때 `AGENTS.md`를 프로젝트 지침으로 읽는다.[2]

둘을 함께 쓰려면 `CLAUDE.md`에서 `@AGENTS.md`를 import하거나, `/config`의 Project instructions를 `claude-md-and-agents-md`로 설정해야 한다. 이 조건을 확인하지 않으면 공통 지침이 Claude Code 세션에 실제로 로드되지 않을 수 있다.[2]

### 사용량 리셋은 계정·기간 의존 정보다

영상은 2026-10-23까지라는 기간 제한을 언급한다.[1] 이 값은 영상 시점의 개인 계정·요금제·프로모션에 의존하는 정보이므로, 재사용 가능한 설정 원칙으로 일반화하지 않는다.[1] 실제 사용 가능 여부와 만료일은 계정의 Usage 화면에서 확인한다.[1]

## 실무 적용 제안

다음은 영상의 개인적 추천을 일반화한 것이 아니라, 공식 문서와 공개 저장소를 함께 보고 정리한 적용 제안이다.

1. **먼저 기본 모델 동작을 관찰한다.** 모든 프로젝트에 대형 스킬 묶음을 설치하지 말고, 반복적으로 실패하거나 시간이 드는 지점을 기록한다.[1]
2. **공통 지침의 단일 원본을 정한다.** 여러 에이전트를 함께 쓴다면 `AGENTS.md`를 공통 원본으로 두고, Claude 전용 지침은 `CLAUDE.md`에서 명시적으로 import하거나 함께 로드하도록 설정한다.[2]
3. **Effort를 작업별로 기록·비교한다.** 동일한 대표 작업에서 낮은 수준과 높은 수준의 결과, 지연, 사용량, 불필요한 변경 범위를 비교한다.[3]
4. **스킬은 전문성 또는 증거 수집에 우선 사용한다.** 릴리스 점검, 프로젝트 고유 절차, 영상·문서 분석처럼 모델이 기본적으로 알 수 없는 정보나 반복적 검증에 집중한다.[1][6]
5. **외부 스킬은 권한을 검토한다.** 설치 전 파일 쓰기, 셸 명령, 네트워크, 다운로드, 외부 API 사용 여부와 업데이트 방식을 확인한다.[4][5][6]
